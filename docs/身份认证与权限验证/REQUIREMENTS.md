# 需求

- 提供登录登出功能
- 提供管理员与用户2种角色
  - 系统初始化好
- 提供用户管理
  - 用户列表
    - 管理员可查看
    - 用户无权限查看
    - 初始默认创建根管理员账号，账号密码均为admin/admin
    - 根管理员账号不可删除
  - 用户创建
    - 管理员可创建
    - 创建用户均为用户角色
  - 用户编辑
    - 管理员可修改用户密码
    - 用户无权限编辑
  - 用户删除
    - 管理员可删除
    - 用户无权限删除
- 权限控制
  - 用户管理界面需要管理员角色才有权限访问
  - 登录页面允许匿名访问
  - 其他业务页面均需要已登录用户支持

# 技术注意点

- 前端相关身份认证与权限验证的组件请参考微软官方的Blazor的例子
- 登录登出操作，使用表单提交，具体实现参考微软官方的Blazor的例子
- 默认管理员初始账号在在第一次启动时在配置里读取自定义的账号密码，初始化完成后无法再通过此方式进行配置
- 使用Blazor组件
