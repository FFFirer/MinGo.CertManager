# v1.0.0

- 按域名申请免费的HTTPS证书
  - 支持多域名
  - 支持泛域名
- 证书申请后国企自动续签
- 证书提供导出功能
  - 支持PFX/P12格式
  - 支持PEM格式
  - 支持CRT/CER格式
  - 支持主要使用场景所需要的格式
- 提供一个列表展示所有已申请证书
  - 字段
    - 证书状态
    - 申请域名
    - 过期时间
  - 查询条件
    - 证书状态
    - 域名，支持模糊搜索
  - 操作
    - 导出
- 使用acme流程申请证书
  - 使用DNS01进行域名所有权验证
  - DNS管理提供商支持阿里云

# v1.1.0

- 导出
  - 使用下载的形式实现导出，默认不在运行目录下生成文件

  - 显示证书生成过程中的必要信息
  - 方便证书申请失败时排查错误
