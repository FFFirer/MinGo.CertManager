# v1.0.0

- 按域名申请免费的HTTPS证书
  - 支持多域名
  - 支持泛域名
- 证书申请后国企自动续签
- 证书提供导出功能
  - 支持PFX/P12格式
  - 支持PEM格式
  - 支持CRT/CER格式
  - 支持主要使用场景所需要的格式
- 提供一个列表展示所有已申请证书
  - 字段
    - 证书状态
    - 申请域名
    - 过期时间
  - 查询条件
    - 证书状态
    - 域名，支持模糊搜索
  - 操作
    - 导出
- 使用acme流程申请证书
  - 使用DNS01进行域名所有权验证
  - DNS管理提供商支持阿里云

# v1.1.0

- 导出
  - 使用下载的形式实现导出，默认不在运行目录下生成文件
- 证书生成日志
  - 显示证书生成过程中的必要信息
  - 方便证书申请失败时排查错误

# v1.2.0

- 实现使用ACME流程申请证书
  - 使用Let's Encrypt的ACME服务
    - 支持切换正式环境/测试环境
  - 使用DNS01挑战
  - 使用阿里云的DNS解析服务接口来维护DNS服务
    - 阿里云身份证支持配置
  - 状态展示
    - 界面展示证书在ACME流程中的阶段状态
    
# v1.2.1

- 添加应用启动自动应用数据库迁移

- ACME流程
  - 缓存
    - 账号等信息，优先检查是否有已缓存的账号
    - 若没有账号，则申请创建新的账号并缓存到本地
    - 若本地有已缓存的账号，则直接使用本地缓存的账号信息，继续剩余操作
  - 流程优化
    - 完成DNS01挑战
    - DNS01挑战流程添加集成测试
    - 使用循环等待处理需要等待结果的场景
